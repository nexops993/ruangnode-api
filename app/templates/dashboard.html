Cara Memakai Token di API

Tiga cara, pilih salah satu:

curl -H "X-Access-Token: TOKEN_KAMU" https://api.ruangnode.me/api

curl -H "Authorization: Bearer TOKEN_KAMU" https://api.ruangnode.me/api

curl "https://api.ruangnode.me/api?token=TOKEN_KAMU"

Respons sukses selalu memakai envelope seragam:

{
  "status": true,
  "creator": "RuangNode",
  "result": { ... }
}
