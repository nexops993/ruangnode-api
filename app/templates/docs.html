Dokumentasi

Base URL: https://api.ruangnode.me · Format: JSON · Bahasa: Bahasa Indonesia

1. API Publik, Tanpa Pendaftaran

RuangNode API terbuka untuk siapa pun. Tidak ada pendaftaran, tidak ada akun, tidak ada biaya — cukup sertakan API key publik di setiap request. Halaman ini pun terbuka untuk dibaca semua orang. Hanya dashboard pemilik yang tetap di balik login.

2. Autentikasi API

API key publik: {{ public_apikey }}. Setiap request ke /api/* (kecuali /api/health) wajib menyertakannya lewat salah satu cara:

CaraContoh
Query?apikey={{ public_apikey }}
HeaderX-Access-Token: {{ public_apikey }}
HeaderAuthorization: Bearer {{ public_apikey }}

3. Format Respons

Sukses:

{
  "status": true,
  "creator": "RuangNode",
  "result": { ... }
}

Gagal (contoh tanpa API key):

{
  "status": false,
  "creator": "RuangNode",
  "message": "Unauthorized: API key tidak ada atau salah."
}

4. Contoh Request

curl -s "https://api.ruangnode.me/api?apikey={{ public_apikey }}"

curl -s "https://api.ruangnode.me/api/download/tiktok?url=URL_TIKTOK&apikey={{ public_apikey }}"

# cek liveness (publik, tanpa key)
curl -s https://api.ruangnode.me/api/health

5. Kode Error

KodeArtiPenyebab umum

404Not FoundPath endpoint tidak ada
429Too Many RequestsMelebihi 600 request / 10 menit per IP, atau IP terkunci akibat key salah berulang
