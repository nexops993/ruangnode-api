Dokumentasi

Base URL: https://api.ruangnode.me · Format: JSON · Bahasa: Bahasa Indonesia

1. Gerbang Access Token

Seluruh dashboard, halaman ini, dan semua request API hanya bisa diakses dengan Access Token. Beranda publik hanya menampilkan gambaran umum. Setelah login berhasil, server menerbitkan cookie sesi bertanda tangan (berlaku 7 hari, httpOnly).

2. Autentikasi API

Setiap request ke /api/* (kecuali /api/health) wajib menyertakan token lewat salah satu cara:

CaraContoh
HeaderX-Access-Token: TOKEN_KAMU
HeaderAuthorization: Bearer TOKEN_KAMU
Query?token=TOKEN_KAMU

3. Format Respons

Sukses:

{
  "status": true,
  "creator": "RuangNode",
  "result": { ... }
}

Gagal (contoh token salah):

{
  "status": false,
  "creator": "RuangNode",
  "message": "Unauthorized: Access Token tidak ada atau salah."
}

4. Contoh Request

curl -s "https://api.ruangnode.me/api" \
  -H "X-Access-Token: TOKEN_KAMU"

# cek liveness (publik, tanpa token)
curl -s https://api.ruangnode.me/api/health

5. Kode Error

KodeArtiPenyebab umum
401UnauthorizedToken tidak disertakan atau salah
404Not FoundPath endpoint tidak ada
429Too Many RequestsTerlalu banyak request (bila rate limit diaktifkan)
500Internal Server ErrorKesalahan tak terduga di server
