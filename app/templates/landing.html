Cara Akses

Tiga langkah, tidak ada pendaftaran dan tidak ada akun.

1

Login dengan token
Pemilik memasukkan Access Token di halaman login untuk membuka dashboard & dokumentasi.

2

Sertakan di request
Setiap panggilan API membawa token lewat header X-Access-Token atau query ?token=.

3

Terima JSON seragam
Semua respons memakai envelope yang sama: status, creator, dan result.

curl -H "X-Access-Token: TOKEN_KAMU" https://api.ruangnode.me/api
