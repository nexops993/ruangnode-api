Cara Pakai

1

Pakai API key publik
Key-nya satu untuk semua orang: {{ public_apikey }}. Tidak perlu daftar.

2

Sertakan di request
Tambahkan ?apikey={{ public_apikey }} di URL, atau header X-Access-Token.

3

Terima JSON seragam
Semua respons memakai envelope yang sama: status, creator, dan result.

curl "https://api.ruangnode.me/api/download/tiktok?url=URL_TIKTOK&apikey={{ public_apikey }}"

Pemakaian wajar saja — server membatasi 600 request per 10 menit per IP demi kestabilan bersama. Dokumentasi tabel lengkap ada di halaman dokumentasi.
